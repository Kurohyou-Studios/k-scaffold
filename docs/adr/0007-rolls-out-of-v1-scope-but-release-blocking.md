# Rolls are out of Foundry v1 scope, but block release

Initial Foundry export work covers actor/item data model and sheets only; the roll/chat-card surface (Roll20's `lib/rolltemplate/` equivalent — Foundry's `Roll` class and chat card templates) is not designed in this phase. This is a sequencing choice, not a cut: Foundry export cannot ship without a working roll surface, so it must be designed and built before release, as a follow-on phase to this work.
