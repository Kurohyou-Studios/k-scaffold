# Compendium packs and Active Effects are deferred

Neither is a prerequisite for a working Actor/Item type system. Compendiums are content packaging/distribution layered on top of it. Active Effects is a distinct Foundry subsystem with its own data model and UI; modeling Roll20-style triggered effects as Active Effects is a separate design question from the static derived-data translation already covered (ADR 0011). Both are deferred, unlike rolls (ADR 0007), neither blocks release.
